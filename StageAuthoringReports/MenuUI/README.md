# タイトル・ステージ選択UI

## 変更内容

タイトルには、中央に「続きから」「ステージを選ぶ」、その下に「遊び方」「終了」を配置した。続きからは保存されている最も進んだ解放ステージを開く。初回はStage1を開く。

以前の「遊び方」ボタンには処理がなかったため、移動・ジャンプ・クローン作成・ポーズ、コイン、死亡復帰を説明する画面を追加した。画像未設定のロゴ欄は非表示とし、仮見出し「2D ACTION GAME」と説明文を配置した。ゲーム名はTitleSceneのTitleHeadingで変更できる。

選択画面はStage1〜3を上段、Stage4〜5を下段中央に配置する。未解放は押せず、クリア済み・挑戦可能・未解放の状態を保存データから表示する。存在しないStage6は非表示。「タイトルへ戻る」は右下に置き、小さい画面で端を越えないよう画面端を基準にした。

両画面の右上の設定、左下の進行データ初期化は既存機能を継続する。ボタンの背景色と文字色、余白を統一し、Canvasを1280×720基準の画面サイズ追従に変更した。日本語TextMeshProフォントを共有アセットとして保存し、編集画面でも日本語を表示できるようにした。

## 配置と編集

Sceneに配置を保存している。通常の実行ではInspectorで調整した位置や見出しを上書きしない。旧配置が残っているSceneだけ実行時に補う。

中央基準の座標（基準解像度1280×720）:

|---|---|---|
|タイトル見出し|(0,205)|800×80|

|ステージを選ぶ|(0,-50)|440×64|
|遊び方／終了|(-116,-130) / (116,-130)|208×56|
|選択見出し|(0,235)|800×70|
|Stage1〜3|(-308,65) / (0,65) / (308,65)|280×128|
|Stage4〜5|(-154,-87) / (154,-87)|280×128|
|タイトルへ戻る|右下基準(-24,80)|280×56|

初期配置を再生成する場合はTools → UI → タイトル・選択画面を整える。再生成は手作業で調整したUI位置を初期配置へ戻すため、通常の調整にはInspectorを使う。

## 確認

開いているUnity Editorはそのままにし、Assets・Packages・ProjectSettingsを複製した検証用プロジェクトで確認した。必要なSceneと共有フォントだけ元プロジェクトに反映した。

- 仮想マウスによる実クリック: 遊び方の開閉、音量設定、続きから、ステージ選択、Stage2への移動、タイトルへの戻り。
- 未解放ステージを押せないこと、Stage6が表示されないこと。
- ボタンの重なり・画面外へのはみ出しを確認。小画面で戻るボタンが少しはみ出す問題は修正した。
- 1280×720・800×600の描画画像を確認。
- テスト終了時に保存設定を復元する。

配置・操作確認の記録はtest.txt。プレビューはtitle-1280.png、title-800.png、selection-1280.png、selection-800.png、how-to-play.png。変更前のSceneはBeforeに保存している。

最終状態の配置・操作確認は131項目成功。ポーズ・音量・フォント・保存・クリア・選択画面の回帰確認は70項目成功（regression-test.txt）。最終ログにコンパイルエラーや実行例外はなかった。終了ボタンは既存のApplication.Quitを維持しており、EditorのPlay Mode自体は終了しない。

検証用Unityの検索インデックス初期化と、回帰テストの結果フォルダ未作成による停止は解消した。日本語字形の確認も、新規追加の成否ではなく必要な字形の存在を確認する方法へ修正した。
