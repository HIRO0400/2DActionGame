# Windows公開前の調整

ゲーム名はユーザー指定の綴りどおり「Clone Advanture」、制作者名は「HIROTO KANO」です。
バージョンは1.0です。タイトル、Player Settings、クレジット、配布説明に反映しました。

- Windows 64bit・Development Build無効の配布用ビルド処理を追加しました。
- 出力先は`Builds/Windows/Clone Advanture.exe`です。
- ビルド時には`Distribution/Windows/README.txt`とクレジットを出力先へコピーします。
- 検証用の`ReleaseUIBuild`は開発ビルドとして維持しました。
- 配布ビルドはまだ実行していません。
- 左右Alt＋Enterはクローン生成として扱いません。Altを離してEnterを押し続けても生成しません。
- ゲーム中にフォーカスを失うとポーズし、戻っただけでは再開しません。タイトル・クリア画面を自動ポーズで置き換えません。
- 1280×720・ウィンドウ起動・サイズ変更可に設定しました。Alt＋Enterによる全画面切替は維持しています。
- クローンPrefabの画像からWindows用アイコンを作成し、Standaloneの各アイコンサイズに設定しました。
- 既存のScene構成、Input System、URP、VSync、音量、ログ出力は維持しています。

Company NameとProduct Nameを変更したため、旧名称で保存したPlayerPrefsと新名称の保存は別扱いです。
旧保存データの削除は行っていません。旧データの移行機能は追加していません。

## 公開前に残っている項目

- 不具合報告先はユーザー回答が「未定」のため、配布説明に未定と記載しています。公開前に実際の窓口へ置き換えてください。
- 対応するWindowsバージョンと必要スペックは実機確認後に確定します。
- WindowsビルドでAlt＋Enter、Alt＋Tab、ウィンドウのサイズ変更、再起動後の保存とアイコン表示を確認します。
- 配布時はexeだけでなく、生成されたフォルダ一式をまとめます。

今回のPlay Mode検証でのフォーカス喪失はコールバックを送信して確認しています。
実際のWindowsの全画面切替・フォーカス・アイコン表示は、後日ビルドしてから確認する必要があります。
