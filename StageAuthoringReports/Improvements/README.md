# Stage1〜5 改善と制作手順

## 配置の方針

| Stage | ゴールX | 主な必須課題 | 上の寄り道 |
|---|---:|---|---|
| 1 | 44.5 | 低い段差、安全な穴、クローンの足場1回 | 一方通行足場とコイン |
| 2 | 112.5 | 見えるトゲ、短い穴、移動足場で渡る穴、敵1体 | 一方通行足場とコイン |
| 3 | 122.5 | 高さ5の壁2回、天井と穴 | 一方通行足場と崩れる足場 |
| 4 | 134.5 | 高さ6の壁、クローンで床スイッチを保持して扉を通過 | 移動足場→崩れる足場 |
| 5 | 142.5 | クローン2段で高さ8の壁、スイッチ保持＋空中の足場を同時に使う壁 | 移動足場→崩れる足場 |

Stage1はゴールを70.5から44.5へ短縮し、クローン壁を2回から1回にしました。
Stage3・5は同じ高い壁を3回繰り返す構成を減らしています。
Stage4のスイッチはX=84、扉はX=94。Stage5のスイッチはX=92、高さ5の壁はX=110〜116、扉は壁の内側のX=112です。
扉の高さはStage4が12、Stage5が18で、壁に登ってからひとつの空中クローンで上から迂回することも防ぎます。
Stage5では、スイッチ上に残すクローンと壁の前に残す空中クローンが同時に必要です。

## ギミックの見分け方

- 水色：下から通り抜け、上から乗れる一方通行足場。
- 黄色→緑：床スイッチ。プレイヤーまたはクローンが乗ると緑になります。
- 青い扉：対応するスイッチで開くと薄い緑になります。扉内にプレイヤーやクローンがある間は閉じません。
- 緑の足場：往復する移動足場。Stage2では地面の上で練習してからX=84〜92の穴を渡ります。
- オレンジの足場：乗ると点滅し、0.85秒後に崩れ、3秒後に再出現します。重なっているプレイヤーを押し出す再出現は行いません。

移動・崩れる足場は復帰地点として記録せず、最後の消えない地面または固定足場に戻ります。
ポーズ中は移動・崩壊・再出現の時間も停止します。既存の移動速度、ジャンプ力、クローン上での生成制限を維持しています。
赤い既存素材でも種類を判別できるよう、足場の上端と扉に色付きの線を表示します。
Stage5の扉前のクローンは、地面から届く高さ（足場上面がおよそ3ユニット）に残すと使いやすくなります。

## 次の調整方法

1. `Tools > Stage Authoring > ステージ制作` を開き、対応する `StageNLayout.asset` を指定します。
2. Inspectorの `terrain / hazards / placements / areas` で地形・危険・既存Prefab・案内を調整します。
3. `platforms` で足場の種類、中心座標、サイズ、移動ベクトル、往復周期、崩壊・復帰時間を設定します。
4. `switchDoors` でスイッチと扉の中心座標、扉サイズを設定します。対応関係は生成時に自動接続されます。
5. Sceneプレビューで移動範囲とスイッチの接続を確認し、配置チェック→現在のSceneの生成配置だけを更新→保存します。
6. 通常ルート、寄り道、死亡後の復帰、クローンの置換、ポーズ、ゴール遷移を確認します。

生成ルートの外の手作業オブジェクトは維持します。案の初期配置を一括生成する `StageImprovementBuilder.Phase4` は配置データを初期案に戻すため、手動調整後は制作ウィンドウから再生成してください。

## 検証

各段階の結果は `phase1-playtest.txt`〜`phase4-playtest.txt`、構造・既存操作の検証は `campaign-validation.txt` と `repair-validation.txt`、既存メニューの検証は `release-ui-playtest.txt` に記録します。
自動攻略は仮想キーボード・マウスで移動、ジャンプ、クローン生成を行います。個別ギミックの接触・安全性検証のみ、開始位置を移す検証を併用します。
初見プレイヤーの所要時間と体感難易度は自動テストでは決められないため、人によるプレイで調整してください。

Unity 6000.3.13f1の検証用プロジェクトで確認し、合格したScene・配置データを本体へ反映しました。

段階内の再実行結果は、同じ配置で通過済みの結果と組み合わせて記録しています。中間診断と変更前バックアップは `.repair-checkpoints/StageImprovements/` に保持しています。
