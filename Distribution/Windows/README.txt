Clone Advanture
制作：HIROTO KANO
バージョン：1.0

Windows 64bit向け

【起動方法】
ZIPを展開し、Clone Advanture.exeを実行してください。
exeだけを移動せず、同梱のフォルダとファイルを一緒に保管してください。

【操作方法】
A / D または ← / →：移動
Space：ジャンプ（長押しで高さを調整）
Enter：クローン生成
Esc：ポーズ／再開
Alt＋Enter：ウィンドウ／全画面切替

【クローン】
クローンを生成すると、最後に接地した地面付近へ戻ります。
クローンは足場や床スイッチの重りとして使用できます。
コインを取ると、同時に置けるクローン数が増えます。
上限数を超えて生成すると、古いクローンから置き換わります。
クローン上に立ったままでは生成できません。ジャンプしてから生成してください。

【保存】
ステージ解放、クリア記録、音量設定は自動保存されます。
ステージ途中の位置やコイン取得状況は保存されません。
進行の初期化はタイトルまたはステージ選択画面から行えます。

【クレジット】
タイトル画面の「クレジット」で素材の提供元をご確認いただけます。
配布フォルダ内のCREDITS.txtにも記載しています。
フォントのライセンス全文は配布データ内のStreamingAssets/Licensesにあります。

【不具合報告】
窓口は未定です。配布前にこの欄を更新してください。
報告時は、バージョン、ステージ、発生までの操作、Windowsの環境を添えてください。

対応するWindowsのバージョンと必要スペックは、配布ビルドの実機確認後に確定します。
